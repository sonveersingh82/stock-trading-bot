# Stock Trading Bot

This project is a starter stock trading bot for paper trading and strategy testing.

## Features
- Historical price loading
- Basic moving-average strategy
- Paper trading simulation
- Broker-ready architecture for Angel One, Dhan, or Yahoo Finance

## Data sources

### Yahoo Finance (default)
This is the easiest way to start quickly and works without any broker credentials.

### Angel One / Dhan
These are broker APIs, not general website scrapers. For production use, you should integrate with each provider's official API.

Important:
- Do not scrape BSE or broker websites in production. It is generally against usage limits and often breaks without notice.
- Use the official brokerage APIs and token/instrument mappings instead.

## Environment variables

For broker integrations, add these to your environment:

```bash
export ANGEL_API_KEY="your_api_key"
export ANGEL_CLIENT_CODE="your_client_code"
export ANGEL_ACCESS_TOKEN="your_access_token"
export ANGEL_SYMBOL_TOKEN_MAP='{"RELIANCE": "2885", "TCS": "11536"}'

export DHAN_API_KEY="your_dhan_api_key"
export DHAN_ACCESS_TOKEN="your_dhan_access_token"
```

## Setup

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python -m app.main
```

## Data provider config

Edit `config/settings.yaml`:

```yaml
provider: yahoo
exchange: NSE
```

Supported values:
- `yahoo`
- `angel`
- `dhan`

When using a broker provider, make sure your symbol map and exchange settings match your broker data feed.

## Example

```python
from app.data import download_price_data

price_data = download_price_data(["RELIANCE", "TCS"], "2023-01-01", "2024-12-31", provider="yahoo")
print(price_data["RELIANCE"].head())
```
